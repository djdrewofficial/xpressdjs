PHOTO BOOTH LANDING PAGE — IMAGES
==================================

EASIEST WAY TO ADD MORE PHOTOS (no renaming headaches):
Just COPY any photos you want to use into this folder with their ORIGINAL
names (e.g. 45_Dinner-with-Friends_Details_Booth_Stock-scaled.jpg). Tell
Claude "done" and it will rename them into the right slots for you. This
avoids the Windows "hide extensions" problem that adds a second .jpg.

(If you'd rather name them yourself: turn on File Explorer > View > "File name
extensions" first, so you don't end up with name.jpg.jpg.)
